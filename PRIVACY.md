# Prompt Relay Privacy Policy

**Last updated:** October 22, 2026

Prompt Relay is a browser extension that lets you write a prompt once and submit it, with optional attachments, to the AI websites you select: ChatGPT, Claude, and Gemini.

## What information Prompt Relay handles

When you use Prompt Relay, the extension handles the content you choose to submit, which may include:

- The text of your prompt.
- Files you deliberately attach, such as images or documents.
- Your selected AI destinations, so the extension can remember your preference.
- A browser window identifier used to reopen or track the Prompt Relay composer window.

Prompt Relay does not need your AI account password or separate AI API keys.

## Where prompts and attachments go

When you send a prompt, Prompt Relay relays the prompt and any selected attachments to the AI website or websites you selected in the composer. The current extension is designed to interact with those websites through your existing browser session; it does not use a Prompt Relay-operated server to receive or store prompt content.

The selected provider receives and processes the content you submit under its own privacy policy, terms, and account settings. The provider may associate submissions with the account you are signed into. Please review the policies of the services you use:

- [OpenAI Privacy Policy](https://openai.com/policies/row-privacy-policy/)
- [Anthropic Privacy Policy](https://www.anthropic.com/legal/privacy)
- [Gemini Apps Privacy Notice](https://support.google.com/gemini/answer/13594961?hl=en)

Only select AI destinations you intend to receive your content. Do not submit passwords, confidential documents, or other sensitive information unless you are comfortable sharing it with the selected provider.

## Local storage

Prompt Relay uses the browser's extension storage to remember interface preferences, including selected AI destinations, and the identifier for its composer window. These preferences are stored by the browser for the extension. Prompt text and attachments are handled to carry out a send action; the extension is not designed to maintain a prompt-history database.

## Analytics, advertising, and sale of data

The current Prompt Relay code does not include a Prompt Relay-operated analytics service, advertising tracker, or backend endpoint for collecting prompts or attachments. Prompt Relay does not sell users' prompts or attachments.

This statement describes the current version. If future versions add analytics, a backend, or other data processing, this policy will be updated before that change is released.

## Permissions

The extension requests browser permissions to access the open tabs, store local preferences, and run its content script on the supported AI websites. These permissions are used to find the selected AI tabs and submit the content you choose to send.

## Data security and retention

Prompt Relay does not independently retain prompt content on a Prompt Relay server. Once content is submitted, the selected AI provider's handling and retention practices apply. Local extension preferences remain in browser extension storage until changed or the extension's data is cleared or the extension is removed.

No software can guarantee that every transmission or third-party service is risk-free. Keep the extension updated and use care when selecting files and AI destinations.

## Children's privacy

Prompt Relay is a general-purpose productivity tool and is not designed specifically for children. Do not use it to submit a child's personal information unless you have the appropriate authority and understand the selected provider's policies.

## Changes to this policy

This policy may be updated when Prompt Relay's features or data practices change. The "Last updated" date above will be revised when a material change is made.

## Contact and support

For questions or privacy concerns, please use the Issues page linked from the Prompt Relay GitHub repository. The repository owner should ensure that its README links to the current public copy of this policy.
